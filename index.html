How to read this page
This reimplements the reference engine's four layers — cas_engine.py, merkle_tree.py, avl_tree.py, storage_engine.py — in client-side JavaScript using crypto.subtle for real SHA-256, so the numbers you see are genuine, not staged.
What's not simulated here
Persistence to disk, garbage collection of zero-refcount blocks, and network transfer are out of scope for a browser demo — see ARCHITECTURE.md for the production roadmap.
